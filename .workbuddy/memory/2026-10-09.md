## APK 产物命名规范化
- 用户要求对齐 `com.elleng.livephototools-1.0.4-universal-release.apk` 的风格：包名-版本名-架构-构建类型。
- 在 `app/build.gradle.kts` 的 `android {}` 加 `applicationVariants.all { outputs.all { if (this is ApkVariantOutputImpl) outputFileName = "${applicationId}-${versionName}-universal-${name}.apk" } }`：
  - 架构段固定 `universal`（本工程单包，无 ABI 拆分，不做花哨的 filters 探测）；
  - 末段 `{name}` 取 variant 实际构建类型（release/debug），不写死 `release`。
- 现产物：`com.elleng.adbswitch-1.0.0-universal-release.apk` / `...-universal-debug.apk`。旧 `app-release.apk` 由 Gradle 自动清掉。
- 坑：Kotlin DSL 里 `BaseVariantOutput.outputFileName` 直接写在 `outputs.all` 里报错「Unresolved reference」，需 `(this as com.android.build.gradle.internal.api.ApkVariantOutputImpl).outputFileName`；`com.android.build.OutputFile.FilterType` 在本 AGP(8.7) 不可解析，别用它。
